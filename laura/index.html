Créer ton jeton (2 minutes)

  1. Ouvre github.com/settings/personal-access-tokens/new (connecté au compte propriétaire du dépôt).
  2. Token name : « FSM SI web ». Expiration : au choix (90 jours conseillé).
  3. Repository access : Only select repositories → fsm-si.
  4. Permissions → Repository :
    • Issues : Read and write
    • Contents : Read and write (envoi de fichiers dans entree/)
    • Actions : Read-only
    • Metadata : Read-only (ajouté tout seul)
  5. Generate token, copie-le et colle-le ci-dessus.

Le jeton reste uniquement dans ce navigateur (stockage local), jamais ailleurs. « Se déconnecter » l'efface.
